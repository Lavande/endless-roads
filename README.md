# 无尽公路 Endless Roads

一个向 Slow Roads 致敬的多主题无尽驾驶网页游戏。纯前端、零构建、零外部运行时依赖（three.js 与后期处理模块均已本地化），低多边形程序化生成，无需任何美术资产。

## 如何运行

任意静态服务器指向本目录即可，例如：

```bash
cd 本目录
python3 -m http.server 8765
# 打开 http://localhost:8765
```

部署到 GitHub Pages / 任意静态托管也可直接游玩。

## 玩法

- **驾驶**：`A/D` 或 `←/→` 转向，`W/S` 或 `↑/↓` 调速（30–200 km/h，随车型上浮），`Shift/空格` 氮气冲到 260+ km/h
- **速度倍率**：开得越快里程分越值钱——100+ km/h ×1.5、160+ ×2、氮气中 ×3，HUD 实时显示
- **险过计分**：贴着车流超车触发「险过」，必须主动转向穿插才计分；对向车流险过 ×1.5 分且音效更尖啸；连续险过叠加连击倍率并触发短暂慢动作
- **越野驾驶**：公路不设边界，可以驶下路基穿越原野；离路越远阻力越大、颠簸越强，撞上树石建筑会被弹开并中断连击
- **车库**：三台性能取向不同的座驾（灵动掀背 / 沉稳 GT / 极速超跑），各有专属涂装、体型与操控/极速/越野/氮气属性；以生涯最高单局分解锁
- **三种模式**：
  - 自由驾驶——禅意兜风，无失败
  - 每日挑战——全球玩家同一天同一条路（UTC 日期做种子）
  - 限时挑战——初始 60 秒，穿过路上的发光光门续时（逐次递减），时间耗尽自动结算
- **里程碑成就**：12 项（连击 / 里程 / 零碰撞 / 极速 / 对向险过…），首次达成奖励分数，主菜单显示进度
- **路途分区**：风景随里程交替（麦浪旷野 / 风车丘陵 / 红岩台地、霓虹峡谷 / 电光旷野、雪松林海 / 冰原 / 雾凇山隘、竹溪幽谷 / 古塔乡野 / 群峰深处），每个分区有专属地标
- **昼夜流转**：约 8 分钟一轮回，在主题美术边界内缓慢入夜再破晓——星空、月色、极光增亮、水墨暮色；可在设置中关闭
- **天气起伏**：粒子密度与雾能见度随低频波动缓慢变化，雪原阵风侧飘
- **收集品**：拾取路上的主题物件（金穗/数据芯片/极光碎片/朱砂墨滴）充能氮气（NOS 满槽点亮）
- **拍照模式**：`P` 进入，拖动旋转 / 滚轮缩放，一键保存壁纸级照片
- **战报分享**：结束旅程生成图片卡片（含车型与模式），支持 Web Share / 保存图片 / 复制文本；最近 10 次行程保存在本地可回看
- **设置**：音量、画质三档（流畅/均衡/精美：分辨率 + 泛光 + 阴影 + 视距）、昼夜流转开关、相机距离，全部即时生效并持久化
- 手机：左右按钮转向、加速/减速控速（松开缓降回巡航）、NOS 氮气；切出标签页自动暂停

## 四大主题

| 主题 | 特色 |
|---|---|
| 黄昏旷野 | 落日、金色麦浪、旋转风车、萤火虫、热气球、星夜变体 |
| 赛博霓虹 | 条纹合成波太阳、星空、霓虹路缘、雨夜光门、UFO、深夜变体 |
| 雪原极光 | 动态极光带、雾凇松林、月色雪坡、极夜极光爆发 |
| 水墨山水 | 宣纸天空、朱砂落日、层叠水墨远山、流动雾带、暮色变体、白鹭 |

每个主题有独立的雾色、光照、天穹 shader、粒子、路缘与收集品配色，以及专属随机环境事件（鸟群/流星/热气球/UFO/极光爆发/光轨…）；界面强调色随主题联动。

## 技术

- **three.js r160**（`vendor/` 本地化，含 EffectComposer + UnrealBloomPass 后期泛光，离线可玩）
- 程序化世界：解析曲线中心线（弯道节奏调制）+ 区块流式生成/回收，种子化（每日挑战全球一致）
- 后期管线：RenderPass → UnrealBloomPass（每主题独立泛光参数）→ OutputPass，HalfFloat + MSAA 渲染目标；移动端直通渲染
- 动态环境：昼夜系统在主题基调与夜变体间插值（天穹/雾/光照/曝光/极光/远山），天气波动联动雾与粒子
- 桌面级细节：PCF 软阴影（窄视锥跟随车辆）、车轮滚动、刹车灯增亮
- 分区系统：确定性区段调度地貌、道具权重与地标，边界平滑过渡
- 全部几何/贴图程序生成：顶点色低多边形、Canvas 生成窗格/辉光贴图、shader 天穹/极光/远山/雾带/地平网格
- 越野物理：地形高度采样贴合车身姿态，道具软碰撞体积随区块登记
- InstancedMesh 收集品与风车叶片、对象池 NPC 车流与特效
- WebAudio 程序化音效：引擎随速变频、风噪、险过 whoosh（对向变调）、拾取/碰撞/氮气/成就音、主题氛围和弦垫
- 桌面 + 手机（触屏按钮、像素比限幅、道具密度自适应、画质档位）
